# 002. 壊す (こわす) と 潰す (つぶす)

## 1. 意思 (意味)

### 壊す (こわす - kowasu)

1.  **弄坏、破坏** (使物品失去原有的功能、形状或完整性，使其无法使用)。
    *   例: 時計を**壊す**。(把表弄坏)
    *   例: 計画を**壊す**。(破坏计划)
2.  **损害、损伤** (使身体或健康状况变差)。
    *   例: 体を**壊す**。(搞坏身体)
    *   例: 健康を**壊す**。(损害健康)

### 潰す (つぶす - tsubusu)

1.  **压碎、弄扁** (通过施加压力使物体变形、扁平或粉碎)。
    *   例: 空き缶を**潰す**。(把空罐子压扁)
    *   例: 虫を**潰す**。(把虫子踩死/压扁)
2.  **毁掉、使破产** (使组织、计划、事业等彻底失败或消失)。
    *   例: 会社を**潰す**。(使公司破产)
    *   例: チャンスを**潰す**。(错过/毁掉机会)
3.  **消磨、打发** (时间)。
    *   例: 時間を**潰す**。(消磨时间)
    *   例: 暇を**潰す**。(打发时间)

## 2. 区别 (違い)

*   **「壊す」** 强调的是“破坏其功能或完整性”，使其不能正常运作或保持原状。可以是物理上的破坏，也可以是抽象的破坏（如计划、关系）。
*   **「潰す」** 强调的是“通过压力使其变形、扁平、粉碎”，或者“使其彻底失败、消失”。它还特指“消磨时间”。

## 3. 使用场景 (使用場面)

### 壊す (こわす)

*   **物理破坏 (失去功能或完整性)**:
    *   子供がおもちゃを**壊して**しまった。(孩子把玩具弄坏了。)
    *   地震で家が**壊れた**。(房子被地震震坏了。) (自动词形式：壊れる)
    *   彼はわざとパソコンを**壊した**。(他故意把电脑弄坏了。)
*   **抽象破坏 (损害、破坏)**:
    *   彼の言葉が私の気持ちを**壊した**。(他的话伤害了我的感情。)
    *   約束を**壊す**わけにはいかない。(不能破坏约定。)
    *   無理な仕事で体を**壊して**しまった。(因为过度劳累把身体搞垮了。)

### 潰す (つぶす)

*   **压扁、粉碎**:
    *   手でパンを**潰す**。(用手把面包捏扁。)
    *   足で空き缶を**潰した**。(用脚把空罐子踩扁了。)
    *   蚊を**潰す**。(拍死蚊子。)
*   **使失败、破产**:
    *   経営に失敗して会社を**潰して**しまった。(经营失败，导致公司破产了。)
    *   彼のせいで、せっかくのチャンスを**潰された**。(因为他，好不容易的机会被毁了。)
    *   ライバル店を**潰す**。(搞垮竞争对手的店。)
*   **消磨时间**:
    *   喫茶店で時間を**潰した**。(在咖啡店消磨时间。)
    *   暇を**潰す**ために本を読んだ。(为了打发时间读了书。)

## 4. まとめ (总结)

*   **壊す**: 强调使物品失去功能或完整性，或损害健康、计划等。
*   **潰す**: 强调通过压力使物体变形、扁平、粉碎；使事业、计划等彻底失败；以及消磨时间。
*   当物体因外力而“损坏”时，两者都可能出现，但侧重点不同：
    *   如果强调的是“不能用了，坏了”，用 **壊す**。
    *   如果强调的是“被压扁了，变形了”，用 **潰す**。
*   对于抽象概念，如计划、机会：
    *   **壊す** 侧重于“破坏、中断”。
    *   **潰す** 侧重于“彻底毁掉、使之失败”。
*   “消磨时间”只能用 **潰す**。
*   “搞坏身体”只能用 **壊す**。
